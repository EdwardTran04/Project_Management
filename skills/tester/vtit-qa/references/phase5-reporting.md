# Phase 5: Reporting

## Bug Report Template

See `references/bug_report_templates.md` for full templates.

### Quick Format

```markdown
# BUG-[ID]: [Clear, specific title]

**Severity:** Critical | High | Medium | Low
**Priority:** Critical | High | Medium | Low
**Module:** [module name]
**TC liên quan:** TC-XXX

## Environment
- Browser, OS, Build, URL

## Steps to Reproduce
1. [Step 1]
2. [Step 2]

## Expected Result
[What should happen]

## Actual Result
[What actually happens]

## Evidence
- Screenshot, Console log, API response
```
