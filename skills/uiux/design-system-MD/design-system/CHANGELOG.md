## [1.0.0] - 2026-05-07

### Added — Initial Release

#### Foundations
- ✨ Design tokens (colors, typography, spacing, radius, shadows)
- ✨ Color palette: Brand, Neutral, Semantic (Success, Warning, Error, Info)
- ✨ Typography scale với font Inter
- ✨ 4px-based spacing scale
- ✨ 8-level grid system
- ✨ 5 levels of elevation
- ✨ Icon system (24x24 grid)
- ✨ Motion tokens (duration, easing)

#### Components — Atomic
- ✨ Button (Primary, Secondary, Tertiary, Destructive)
- ✨ Input, Textarea, Select
- ✨ Checkbox, Radio, Toggle
- ✨ Badge, Tag, Avatar
- ✨ Icon Button

#### Components — Molecules
- ✨ Card, Dropdown, Tooltip
- ✨ Toast, Alert
- ✨ Accordion, Tabs

#### Components — Organisms
- ✨ Modal, Table, Data Table
- ✨ Navbar, Sidebar
- ✨ Form, Pagination

#### Patterns
- ✨ Dashboard layout
- ✨ Authentication flow
- ✨ Empty states
- ✨ Form patterns
- ✨ Navigation patterns
- ✨ Pricing card

#### Guidelines
- ✨ WCAG 2.2 AA compliance
- ✨ Content voice & tone
- ✨ Responsive breakpoints
- ✨ Dark mode support
- ✨ Do's and Don'ts

#### Handoff
- ✨ Developer guide
- ✨ Tokens export (JSON, CSS, SCSS)
- ✨ React usage examples

- ✨ Figma to Code workflow

## Versioning Strategy

- **MAJOR (X.0.0)**: Breaking changes (token structure, component API)
- **MINOR (1.X.0)**: New components, new tokens (backward compatible)
- **PATCH (1.0.X)**: Bug fixes, documentation updates

## How to read this changelog

- ✨ **Added** — new features
- 🔄 **Changed** — changes in existing functionality
- ⚠️ **Deprecated** — soon-to-be removed features
- 🗑️ **Removed** — removed features
- 🐛 **Fixed** — bug fixes
- 🔒 **Security** — vulnerability fixes
