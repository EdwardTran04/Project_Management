# RACI Matrix — Dự Án AI-WMS

> **R** = Responsible (Thực hiện) | **A** = Accountable (Chịu trách nhiệm) | **C** = Consulted (Tham vấn) | **I** = Informed (Được thông báo)

---

| Hoạt động | Product Owner | PM | BA Lead | Dev Lead | Test Lead |
|---|:---:|:---:|:---:|:---:|:---:|
| Phê duyệt yêu cầu | A | I | R | C | I |
| Viết SRS/PTYC | C | I | R/A | C | C |
| Thiết kế kiến trúc | I | I | C | R/A | I |
| Code & Unit Test | I | I | I | R/A | I |
| Viết Test Case | I | I | C | I | R/A |
| Kiểm thử tích hợp | I | A | C | C | R |
| Quản lý CR | A | R | R | C | C |
| UAT / Sign-off | R/A | I | C | I | I |
| Báo cáo tiến độ | I | R/A | C | C | C |
